# Efe Baran Durmaz

I build developer tools for running and reviewing work done by coding agents. I study Information Systems and Technologies at Bilkent University and expect to graduate in June 2027.

## What I’m building

- **Fabric** helps a coding agent find a compatible machine for a job and continue on another runner with its workspace, uncommitted changes, and supported agent session intact. [Fabric](https://github.com/EfeDurmaz16/fabric)
- **Capsule** gives developer tools one interface for starting sandboxes and running code on different cloud providers. Each adapter exposes what its provider supports. [Capsule](https://github.com/EfeDurmaz16/capsule)

In one prototype test, Fabric recovered the same Codex session and workspace in a Vercel sandbox after the runner rebooted. [Recovery notes](https://github.com/EfeDurmaz16/fabric/pull/60)

## Selected open source contributions
